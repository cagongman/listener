# Recording cues

- `record_start.wav`: Kenney Interface Sounds `maximize_007.ogg` (rising).
- `record_stop.wav`: Kenney Interface Sounds `minimize_007.ogg` (falling).
- Both are approximately 0.183 seconds, 44.1 kHz, mono, PCM 16-bit WAV.
- Converted from OGG with amplitude multiplied by 0.35.

Creator: Kenney (https://kenney.nl/assets/interface-sounds).
